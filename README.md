# 战鸽助手

Windows 桌面助手，登录 [战鸽](https://zhange.space) 账号后使用。主菜单有战鸽酒馆和逃离塔科夫。

塔科夫里可以综合搜索，也可以看大厅、物品图鉴、弹药对照、商人、Boss、藏身处、工作台和钥匙。实时地图和任务管理可以开私人房间，和队友同步任务进度、任务目标，以及战局里的位置。地图可以做成覆盖层。右上角可以切换 PVP / PVE。

妙妙工具里有屏幕色彩、健身计时、游戏目录绑定和历史任务回填。截图设置可以指定战局截图按键；游戏把坐标写进截图文件名后，助手会标在当前地图上，并同步给同一房间的队友。本地或离线战局的日志里没有地点时，进图会挂到这里选的离线地图，回到菜单不会强行切图。清理打开后，游戏截图超过保留张数就删最旧的，最新一张始终留下。

日志监控会在游戏运行时读取本机日志，用来切图、识别 PVP / PVE、提示战局开始，并把任务状态写回账号。综合搜索顶部会显示三狗最近的出没地图。任务名可以点开对应的百科。

日志原文留在本机。历史同步和实时监控只把解析出的任务状态发给战鸽。房间同步走战鸽的房间连接，只发送任务进度、战局阶段和截图坐标。

覆盖层快捷键默认是 `M`，并且只在自己还留在房间里时生效。在输入框里打字时不会触发。调节屏幕色彩和健身计时需要管理员权限，程序清单里已经声明。

配置写在 `%APPDATA%\space.zhange.app\`：

| 文件 | 内容 |
| --- | --- |
| `session.json` | 登录会话 |
| `paths.json` | 截图目录、日志目录 |
| `overlay.json` | 地图覆盖层 |
| `miaomiao.json` | 视觉方案和健身延迟 |
| `shot.json` | 截图按键、离线地图、旧图清理 |

```bash
npm install
npm run tauri dev
```

也可以双击 `start.bat`。

推送 `v*` 标签后，GitHub Actions 会打出一份 32 位的 `zhange-app.exe`，并挂到同名 Release。这份程序在 32 位 Windows 上直接运行，在 64 位 Windows 上由系统的 32 位兼容层运行。在 Actions 页手动运行 `build` 时，用 `src-tauri/tauri.conf.json` 里的版本号发布。
