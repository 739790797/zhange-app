# 战鸽助手

Windows 桌面助手，登录 [战鸽](https://zhange.space) 账号后使用。主菜单有战鸽酒馆和逃离塔科夫。

塔科夫里可以综合搜索，也可以看联机大厅、实时地图、物品图鉴、弹药对照、Boss、藏身处、枪匠工作台、钥匙、任务和日志监控。商人从综合搜索或任务页进入。实时地图和任务管理可以开私人房间，和队友同步任务进度、任务目标，以及战局里的位置。选图页点一张图，只切换自己正在看的地图；卡片下面是正在这张图里的人，匹配中和观战中会另外标出，三狗最近的出没点也标在对应地图上。联机大厅按成员列出房间，能看到每个人的地图，以及战局中、匹配中、观战中或大厅中。还没选地图、而且只有自己一个人的房间，离开选图页或打开大厅时会自动退出。地图可以做成覆盖层。底图、楼层和筛选记在账号上。顶部可以后退、前进，右上角可以切换 PVP / PVE。

物品图鉴按类别列出属性，点开可以看商人买卖、跳蚤、配方、任务和枪械预设。弹药对照、Boss、藏身处、钥匙和工作台也用同一套列表。

妙妙工具里有屏幕色彩、健身计时、游戏目录绑定和历史任务回填。截图设置可以开关位置同步。截图按键读取游戏里的截图设置；读到了就显示游戏里的键名，读不到就沿用以前保存的键。游戏把坐标写进截图文件名后，助手按文件修改时间取最新一张，标在当前地图上，并同步给同一房间的队友。同步关掉后不再读新截图，也不再自动按键或清理旧图。自动截图打开后，只在本机日志显示已经进图、且游戏窗口在前台时，按设定间隔按下这个键。按下的一瞬间会先挡住妙妙和覆盖层快捷键，避免同一次按键把它们也触发。打开自动截图时会一并打开旧图清理。清理按修改时间删最旧的，最新一张始终留下。日志里读不到地点时，不会替你选一张离线地图。

日志监控会读取最近一次启动的本机日志。游戏开着时，用来切图、识别 PVP / PVE、提示战局开始，并把任务状态写回账号。人已经在战局里、并且当前还留在房间里时，会切到对应地图。游戏没开时，不会把日志里的上一次战局当成还在进行。日志监控页可以看到这次启动的状态，以及应用、通知、后端三份日志的末尾和触发记录。综合搜索顶部会显示三狗最近的出没地图。任务名可以点开对应的百科。

日志原文留在本机。历史同步和实时监控只把解析出的任务状态发给战鸽。房间同步走战鸽的房间连接，只发送任务进度、战局阶段和截图坐标。地图筛选保存在账号里。

覆盖层只在战局进行中能打开，离开战局会自动关掉。快捷键默认是 `M`，游戏窗口或覆盖层本身在前台时才响应。在输入框里打字时不会触发。全屏按当前显示器铺满。调节屏幕色彩和健身计时需要管理员权限。发布出去的程序会在启动时申请；本地调试构建不会弹 UAC。

界面字体随程序打包：中文用 Noto Sans SC，英文和数字用 IBM Plex Sans，等宽用 IBM Plex Mono。

配置写在 `%APPDATA%\space.zhange.app\`：

| 文件 | 内容 |
| --- | --- |
| `session.json` | 登录会话 |
| `paths.json` | 截图目录、日志目录 |
| `overlay.json` | 地图覆盖层 |
| `miaomiao.json` | 视觉方案和健身延迟 |
| `shot.json` | 截图同步、截图按键、自动截图、旧图清理 |

```bash
npm install
npm run tauri dev
```

也可以双击 `start.bat`。

推送 `v*` 标签后，GitHub Actions 会打出一份 32 位的 `zhange-app.exe`，并挂到同名 Release。这份程序在 32 位 Windows 上直接运行，在 64 位 Windows 上由系统的 32 位兼容层运行。在 Actions 页手动运行 `build` 时，用 `src-tauri/tauri.conf.json` 里的版本号发布。
